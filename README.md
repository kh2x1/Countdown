# 💰 جمعية الأشهر

موقع ثابت بسيط لحجز أشهر الجمعية، يعمل مباشرة على **GitHub Pages**. كل شخص يسجّل
الدخول **باسمه فقط**، ويحجز **شهراً واحداً** ليستلم فيه الجمعية، و**لا يمكن لأحد تغيير
أو إلغاء حجز شخص آخر**.

> جمعية من ٣٠٠ ريال يتم تحويل الجمعية نهاية كل شهر ميلادي حسب الراتب، بحد أقصى أسبوع
> لا أكثر من ٢٧ إلى ١ من الشهر التالي.

## المميزات

- تسجيل الدخول بالاسم فقط (بدون كلمة مرور).
- ١٢ شهراً للحجز: يونيو حتى مايو (نفس ترتيب الفكرة الأصلية).
- **شهر واحد لكل شخص** — لازم تلغي حجزك الحالي قبل ما تغيّره.
- صاحب الحجز وحده يقدر يلغي حجزه؛ ما تقدر تعدّل حجز غيرك.
- واجهة عربية (RTL) تعمل على الجوال والكمبيوتر.
- بدون أي خادم أو مكتبات — موقع ثابت 100%.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو شغّل خادم بسيط:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر على GitHub Pages

### الطريقة الأسهل (Deploy from branch)
1. ادفع الملفات إلى فرع `main`.
2. من المستودع: **Settings → Pages**.
3. تحت **Source** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
5. بعد دقيقة يصير الموقع متاح على:
   `https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

### الطريقة الآلية (GitHub Actions)
يوجد ملف `.github/workflows/pages.yml` ينشر تلقائياً عند كل دفعة إلى `main`:
1. من **Settings → Pages → Source** اختر **GitHub Actions**.
2. ادفع إلى `main`، وبيشتغل النشر تلقائياً.

## ملاحظة مهمة عن التخزين

هذه نسخة **محلية**: الحجوزات تُحفظ في `localStorage` داخل متصفح كل شخص، يعني
**لا تتشارك بين الأجهزة**. مناسبة للتجربة والعرض. لو حبيت جمعية حقيقية تتشارك بين
الجميع على أي جهاز، نحتاج تخزين مشترك (مثل Firebase) — وهذا متاح كترقية لاحقة.
