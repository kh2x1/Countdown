# 💰 جمعية الأشهر

موقع بسيط لحجز أشهر الجمعية. كل شخص يسجّل الدخول **باسمه فقط**، ويحجز شهراً واحداً
(أو أكثر) ليستلم فيه الجمعية، و**لا يمكن لأحد تغيير أو إلغاء حجز شخص آخر**.

> جمعية من ٣٠٠ ريال يتم تحويل الجمعية نهاية كل شهر ميلادي حسب الراتب، بحد أقصى أسبوع
> لا أكثر من ٢٧ إلى ١ من الشهر التالي.

## المميزات

- تسجيل الدخول بالاسم فقط (بدون كلمة مرور).
- ١٢ شهراً للحجز: يونيو حتى مايو (نفس ترتيب الفكرة الأصلية).
- كل شهر يُحجز لشخص واحد فقط — أول من يحجز.
- صاحب الحجز وحده يقدر يلغي حجزه؛ الخادم يرفض أي محاولة لتعديل حجز الآخرين.
- واجهة عربية (RTL) تعمل على الجوال والكمبيوتر.
- بدون أي مكتبات خارجية، والبيانات تُحفظ في ملف `data.json`.

## التشغيل

يتطلب Node.js (الإصدار 16 أو أحدث):

```bash
npm start
```

ثم افتح المتصفح على: <http://localhost:3000>

لتغيير المنفذ:

```bash
PORT=8080 npm start
```

## الاختبارات

```bash
npm test
```

## كيف يعمل الحجز بأمان؟

عند تسجيل الدخول يُنشئ الخادم جلسة مرتبطة بالاسم (كوكي `session`). أي عملية
حجز أو إلغاء تتحقق من الجلسة على الخادم، وإلغاء الحجز يُسمح به فقط إذا كان اسم
صاحب الجلسة مطابقاً لاسم صاحب الحجز — وبذلك لا يستطيع أحد العبث بحجز غيره.
