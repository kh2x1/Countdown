# ⏳ العدّ التنازلي للمناسبات

تطبيق ويب بسيط يعرض **عدّاد تنازلي** للمناسبات المهمة (كأس العالم، زواج، سفر... إلخ).
يعرض كم باقي بالشهور والأيام والساعات والدقائق والثواني — وليس منبّهاً.

## المميزات

- ➕ إضافة عدد غير محدود من المواعيد (اسم + تاريخ ووقت).
- ⏱️ عدّاد تنازلي يتحدّث كل ثانية تلقائياً.
- 📅 يعرض المتبقي بالشكل: **شهر / يوم / ساعة / دقيقة / ثانية**.
- 🗑️ حذف المواعيد بسهولة.
- 🔒 تُحفظ مواعيدك في متصفحك فقط (localStorage) — بدون أي خادم.
- 📱 واجهة عربية متجاوبة تعمل على الجوال والكمبيوتر.
- 📲 يدعم **الإضافة إلى الشاشة الرئيسية** بأيقونة خاصة (PWA).

## التشغيل محلياً

افتح ملف `index.html` مباشرة في المتصفح. لا يحتاج أي تثبيت.

## النشر على GitHub Pages

1. ادمج هذا الفرع في فرع `main`.
2. من إعدادات المستودع: **Settings → Pages**.
3. تحت **Build and deployment**، اختر **Source: GitHub Actions**.
4. سيتولّى ملف `.github/workflows/deploy.yml` النشر تلقائياً عند كل دفعة إلى `main`.

بعد اكتمال التشغيل سيكون الموقع متاحاً على:
`https://<اسم-المستخدم>.github.io/<اسم-المستودع>/`

## الملفات

| الملف | الوصف |
|-------|--------|
| `index.html` | هيكل الصفحة |
| `style.css` | التصميم (وضع داكن، متجاوب) |
| `app.js` | منطق العدّاد والتخزين |
